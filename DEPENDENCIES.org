:PROPERTIES:
:CUSTOM_ID: dependency-licenses

Orrisd source is licensed under Apache-2.0. Separately maintained packages retain
their own licenses. This repository records locked dependencies without vendoring
their implementations or distributing compiled artifacts.

The table records licenses from the exact Hex archives pinned in ~mix.lock~.
Archive checksums were compared with the lockfile, and upstream license/notice
files were inspected. License spellings are normalized to SPDX identifiers;
for example, gproc declares “APL 2.0” and includes the Apache License 2.0 text.
“Transitive” means present in the lockfile but not a direct project dependency.

** Build tools and runtime programs
:PROPERTIES:
:CUSTOM_ID: build-tools-and-runtime-programs
:END:
The Nix flake pins nixpkgs and devenv for the BEAM toolchain and build utilities.
Those inputs and the pinned GitHub Actions retain their upstream licenses.
Runtime commands use separately installed tools such as tmux and agent CLIs;
those programs are not bundled source in this repository.

The IPC fixture corpus consists of synthetic protocol examples shared with
Orris, developed under common project authorship. Terminal fingerprint captures
have personal account and workspace content replaced with generic examples
while preserving the classifier signals.

A binary release, container, or redistributed Nix closure requires a review of
the exact bundled dependencies and their notices. This source inventory does
not certify those distributions.
